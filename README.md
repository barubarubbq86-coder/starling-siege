# スターリング・シージ ブラウザ版

GitHub Pagesで公開できる静的HTMLゲームです。

## 公開方法

1. GitHubで新しいリポジトリを作成します。
2. このZIPを展開し、中にある `index.html` をリポジトリの一番上に置きます。
3. Settings → Pages → Deploy from a branch → `main` / `/ (root)` を選びます。
4. 数分後に表示されるURLを開きます。

## 画像の登録

- 味方キャラクター：Google Emoji Kitchen（https://emoji.kitchen/）で作った画像を保存し、ゲームの「組み合わせ工房」から読み込みます。
- 敵キャラクター：いらすとや公式サイトから利用規約を確認して素材をダウンロードし、敵画像として読み込みます。

読み込んだ画像はブラウザの端末内保存だけで、外部サーバーへ送信しません。

いらすとや素材を使う場合は、必ず公式の利用規約（https://www.irasutoya.com/p/terms.html）を確認してください。著作権は放棄されておらず、素材を主体とした再配布・販売などは禁止されています。

# スターリング・シージ：オフライン版

ユーザー提供の敵画像20枚（モブ15体、ボス5体）を含む、家庭内で遊ぶためのオフライン版です。GitHub Pages、独自ドメイン、アカウントは不要です。絵やセーブはこのパソコンのブラウザ内に保存します。画像20枚を8ステージに配置し、ボスの数字が大きいほど強くしています。

## Windowsで遊ぶ

1. ZIPを**すべて展開**します。ZIPの中から直接ファイルを開かないでください。
2. 展開したフォルダの `START_GAME.bat` をダブルクリックします。Python 3が必要です。
3. 既定のブラウザで `http://127.0.0.1:8765/` が開きます。開かない場合はそのアドレスを手入力します。黒い起動用ウィンドウは遊ぶ間、開いたままにします。
4. 終えるときは起動用ウィンドウで `Ctrl+C`、またはウィンドウを閉じます。次回は同じファイルから起動します。

Python 3がまだない場合は、保護者がPython公式サイトからインストールしてください。ゲーム自体は外部のライブラリを使いません。

macOS・Linuxでは展開したフォルダで `python3 launch.py` を実行します。`start.sh` からも起動できます。

## 遊び方

- 「今すぐテストプレイ」で開始。味方ボタンで生産、働き手を増やしてお金の生産量を上げます。戦闘画面を左右にドラッグするとスクロールします。
- 工房でキャラやステージを組み合わせて作れます。敵の表示名も変更できます。
- ペイントで絵を描いて味方に設定できます。ペン、消しゴム、色、太さ、戻す／やり直す、下書き保存があります。パラパラ漫画機能はありません。
- 緑背景の手描きPNG・JPEG・WebP（8MB以下、各辺4000px以下）を取り込み、背景を透明にして味方に設定できます。
- 最大HPの20%ぶんのダメージを受けるたび、味方・敵ともに傾いて2度跳ねます。

## セーブと安全性

- `launch.py` は `127.0.0.1`（このパソコン自身）だけで待ち受けます。許可したゲームファイルだけを配信し、外部サイトへの通信処理、広告、解析タグ、チャット、外部リンクはありません。画面には通信を制限するCSPも設定しています。
- XP・進行状況・名前はブラウザのlocalStorage、絵と下書きはIndexedDBに保存します。ブラウザのサイトデータを削除すると消えます。共有パソコンでは同じブラウザを使う別の人が絵を見られます。
- 保存先は `http://127.0.0.1:8765` に固定しています。`index.html` を直接開いた場合や別ポートで起動した場合は別の保存領域になります。以前のGitHub Pagesの絵・セーブも自動では移りません。
- このZIPを公開リポジトリにアップロードしないでください。画像の扱いは `ASSET_NOTICE.md` を参照してください。
